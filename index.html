Inferno Tower - Stroboscopic Effect Fountain

Feb 2026 - Ongoing

Overview

This project is a lighting design project inspired by the Inferno Tower from Clash of Clans, designed for the Lutron Lighting Competition. It recreates the stroboscopic effect, where precisely timed pulsing lighting makes flowing water appear levitating or moving in slow motion. The goal was to create an interactive display that combines visual aethetics, engineering principles, and embedded systems.

Process

The Inferno Tower was 3D modeled in Blender then 3D printed to house all components cleanly. We used an Arduino Nano to control the strobing lights and a PWM-driven water pump. A rotary encoder, mini OLED display, and push button were used as UI to intuitively control timing parameters like pulse frequency and pump power. Components were initially soldered to a perfboard, but we plan on using a custom PCB for a more finalized design.

Results

The project is still ongoing. We plan on improving our prototype despite the competition ending. We strengthened our skills in rapid prototyping, system integration, and adapting to critical issues like part delays.

Portfolio Website

Jan - Mar 2026

Overview

An interactive 3D portfolio for displaying past and ongoing projects in an aesthetic scene. The scene is my (ideal) room modeled in Blender, rendered with Three.js and WebGL, features clickable objects, animated elements, and light/dark modes. My idea for this project was to create a functional portal to showcase my work, while keeping the website fun and engaging.

Process

The room was modeled and baked in Blender with image texture sets to avoid real-time lighting costs. I used WebGL to handle scene rendering, Three.js for texture and glTF model loading, and OrbitControls for camera movement. Raycasting and GSAP makes the website more interesting through its animations: modal transitions, object transformations, and a custom intro scene. GPU preloading day/night textures creates seamless transitions between light/dark modes.

Results

Building this was one of the most fun and valuable projects I've worked on: went from complete beginner in Blender and Three.js to having a polished 3D website. Designing my portfolio taught me a lot about Blender, Three.js, GSAP, and web development. The website UI feels intuitive, smooth, and finalized. I'm continuing to develop new features and improvements for the website.

Social Network Graph App

Nov - Dec 2025

Overview

C++ desktop application built for EC327 (Intro to Software Engineering) that simulates and visualizes a social network of students. Users can load or generate datasets, explore social adjacency, and find minimum “degrees of separation” between any two people. The project was developed by a team of five using Agile practices, with a Qt-based GUI layered on top of a modular, dependency-injected backend.

Process

The core simulation in SocialGraph.cpp treats each Person as a node and builds directed edges based on a configurable similarity score across attributes like region, graduation year, favorite colors, and engineering focus. Users adjust category weights and a top-N neighbors setting to control which edges are kept. Multiple PersonReader implementations (CSV, HTTP+JSON, and random generation) are wired in via Inversion of Control and Dependency Injection. A Qt interface connects this logic to a graphical view, letting users load, edit, persist, and explore datasets while running BFS-based pathfinding and traversal under the hood.

Results

Delivered a fully interactive social graph application with directed, weighted edges driven by a configurable similarity model. The system supports CSV, HTTP+JSON, and synthetic data sources, along with autosave, reload, and in-place editing of Person records. Users can visualize the network in real time, navigate by clicking nodes or entering IDs, and highlight shortest paths between arbitrary people. The final application met all EC327 requirements, including modular data loading, persistence, configurable edge logic, and a documented simulation-generated social graph.

Truss Simulation & Optimization

Nov - Dec 2025

Overview

A MATLAB program that analyzes and optimizes truss structures by computing internal forces, failure loads, and critical members — then physically constructs and validates the optimal design.

Process

Static force analysis was implemented using the method of joints. A Monte Carlo simulation iterated over thousands of geometry variations, scoring each against load capacity and cost efficiency. A buckling-strength regression and constraint verification system were added to filter invalid configurations. A MATLAB GUI allowed interactive truss editing and real-time visualization of results.

Results

The optimized design achieved 72.6% increased load above the minimum capacity — the strongest valid design in the class. An acrylic truss was constructed from the optimal model and physical testing closely matched calculated predictions.

Automatic Liquid Dispenser

Sep - Dec 2025

Overview

A contactless automatic soap dispenser designed to meet a real client brief. Led a team of 4 through the full product design lifecycle from requirements gathering to physical delivery.

Process

Requirements were captured through client interviews and translated into engineering specifications. The enclosure was designed for compact integration of an Arduino, IR sensor, peristaltic pump, and OLED display. Firmware was developed to handle sensor debouncing, pump timing for consistent 25mL dispensing, and an animated water level UI. Multiple prototypes were iterated on before the final enclosure was printed.

Results

Delivered a working product to the client with 95% detection accuracy and consistent dispensing volume. The OLED UI provided clear real-time feedback and the compact enclosure met all client size requirements.

Temperature Monitoring Device

Apr - May 2025

Overview

An introduction to the full embedded and mechanical engineering workflow — from firmware to physical fabrication. A standalone Arduino device that monitors temperature and alerts the user when readings fall outside a configurable range.

Process

The enclosure was modeled in Onshape and fabricated via FDM 3D printing. Firmware was written in Arduino C to read temperature sensors, display live readings on an LCD, and trigger visual and audible alerts based on user-set thresholds. Components were hand soldered onto a PCB for a clean final build.

Results

A fully functional temperature monitor with reliable alerting and a clean enclosure. This project established foundational skills in embedded systems, CAD modeling, and electronics fabrication that carried through all subsequent projects.
